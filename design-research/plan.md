# Direction plan (Phase 3)

Written against: 67dcc45 (main, 2026-10-01). Evolves the approved "Evidence Dossier" (web/DESIGN.md, locked 2026-09-26). Not replaced: the baseline reviewer-grade point of view is 4 (see rubric scores in report.md), above the "under 3" replacement bar.

## What the baseline gets wrong (from design-research/screens/before)
1. The case-file metaphor lives in the hero and in a few components; everywhere else a section is a plain mono eyebrow over a serif heading, so a page with the logo covered reads as "tasteful editorial SaaS", not as Personaudit.
2. The main action (grade a URL) is a link to another page. The URL field is ~900px down the home page, and on `/for-agencies` and `/pricing` there is no grade field at all.
3. Mobile home is ~12,000px. The six-card crawl map alone is ~2,100px.
4. No considered motion. The one "moment" a document product owns (a stamp landing, a highlighter pass) is absent.

## Direction (one)
- **Type:** unchanged system: Newsreader 500 display (upright), IBM Plex Sans UI, IBM Plex Mono evidence. Scale tightened: H1 clamp(2.6rem,5.6vw,4.5rem), H2 clamp(1.9rem,3.4vw,2.6rem). Mono is the *evidence voice only*: IDs, counts, commands, exhibit tabs.
- **Palette:** unchanged OKLCH tokens (desk, sheet, ink, ink-blue, redline, highlighter). One filled primary per view.
- **Spacing/layout:** `.frame` / `.frame-narrow`, asymmetric 0.85/1.15 grids, ledgers with a 2px ink head. No 3-up icon cards.
- **Imagery:** none generated. The brand is drawn in CSS and type (sheets, stamps, rules); imagery budget spend is $0 and no provenance file is needed. A stock photo or AI illustration would contradict the honesty wall.
- **Motion:** 3 moments only, all `transform`/`opacity`/`background-size`, all disabled under `prefers-reduced-motion`: highlighter sweep on the page claim (600ms, once), stamp lands on the hero sheet (280ms, once), exhibit tab rule draws in on view is NOT used (no scroll-jacking).
- **References it draws from:** Tufte (marginalia, cream ground), Field Notes (serial-numbered editions, label-as-cover), The Pudding ("#224 · AUG 2026" index chips), Kinfolk (issue numbering), Siteimprove/WAVE (the URL field in the first screen).

## Signature moves (repeat on every page)
1. **Exhibit tabs.** Every major section opens with a manila file-tab sitting on a 2px ink rule: `EXHIBIT A · Procedure`. Letters are generated by a CSS counter (A, B, C ... per page), so no page can number them wrong and there is no JS. Replaces the plain `label-mono` eyebrows on home, agencies, pricing, docs and guide headers.
2. **The highlighter pass.** Each page's H1 carries exactly one highlighted claim phrase (`.mark-sweep`), the same gesture the hero sheet uses on evidence. It sweeps in once. A visitor who sees only a heading with a yellow ink pass on one phrase is on Personaudit.
3. **Bates serials.** Every sheet-shaped object (hero sheet, sample report cover, auth card, 404 card, footer) carries a mono Bates-style serial (`PA-0426-0003`) in the lower margin, the way a produced legal document is numbered. The number is a decoration only and never claims a count.

## Anti-generic check
Gradient/glow hero: none. Three equal cards: removed (crawl map becomes a ledger on mobile, deliverables stay a definition list). Glassmorphism: header uses 85% solid background with a 6px blur only for legibility, no tint card; kept as is. Default Inter + purple: no, Newsreader/Plex + ink blue. Emoji/stroke icon decoration: none. Logo wall, unsourced counters, stock people: none. Centered-everything: none; all sections are left-aligned asymmetric grids except the 404/auth cards (functional, single-purpose).
